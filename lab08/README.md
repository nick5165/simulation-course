### 2. Краткие теоретические сведения

**Пуассоновский поток событий** (или простейший поток) обладает свойствами стационарности, ординарности и отсутствия последействия. 

1. **Интервалы времени между событиями**:
   В пуассоновском потоке с интенсивностью $\lambda$ (среднее число событий в единицу времени) интервалы времени $\Delta t$ между последовательными событиями распределены по показательному (экспоненциальному) закону с плотностью:
   $$f(t) = \lambda e^{-\lambda t}, \quad t \ge 0$$
   
   Моделирование таких интервалов осуществляется методом обратной функции через базовую случайную величину $\alpha \in (0, 1]$:
   $$\Delta t = -\frac{\ln(\alpha)}{\lambda}$$

2. **Закон распределения числа событий**:
   Число событий $k$, попадающих в фиксированный интервал времени $T$, распределено по закону Пуассона. Теоретическая вероятность получить ровно $k$ событий за время $T$ рассчитывается по формуле:
   $$P(X = k) = \frac{(\lambda T)^k \cdot e^{-\lambda T}}{k!}$$

3. **Числовые характеристики**:
   Для распределения Пуассона теоретическое математическое ожидание $M[X]$ и дисперсия $D[X]$ равны между собой и определяются параметрами потока и длиной интервала:
   $$M[X] = D[X] = \lambda T$$

### 3. Структура проекта

Проект разделен на два модуля:
1. `simulation.py` — расчетный модуль. Содержит мультипликативный конгруэнтный генератор псевдослучайных чисел, класс моделирования потока событий и функцию расчета статистических показателей.
2. `gui.py` — модуль графического интерфейса. Реализует форму ввода параметров, отображает числовые результаты и строит график сравнения эмпирического и теоретического распределений.

### 4. Описание реализации

#### Генератор случайных чисел
Используется собственный мультипликативный конгруэнтный генератор (класс `MultiplicateConGenerator`):
* Модуль: $M = 2^{63}$
* Множитель: $\beta = 2^{32} + 3$
* Начальное состояние: $x_0 = \beta$

#### Моделирование интервалов
Класс `FlowCalculations` реализует $N$ независимых экспериментов. В каждом эксперименте последовательно генерируются интервалы времени $\Delta t$ до тех пор, пока суммарное время не превысит заданный предел $T$. Количество событий, попавших строго внутрь интервала $[0, T)$, возвращается в качестве результата единичного опыта.
