# Моделирование случайных событий (GUI)

**Часть 1:**
Приложение «Заказывать ли сегодня доставку еды?».

**Часть 2:**
Приложение «Шар предсказаний: Чем заняться на выходных?» (Magic 8-Ball).

## Описание

Приложение демонстрирует моделирование случайных событий с неравномерными вероятностями на языке Python с использованием современного графического интерфейса на базе библиотеки `CustomTkinter`. 

В основе реализации лежит пользовательский генератор псевдослучайных чисел (`MultiplicateConGenerator`), использующий мультипликативный конгруэнтный метод. Встроенные библиотеки для получения случайных чисел (например, стандартный модуль `random`) принципиально не применяются.

Выбор случайного исхода выполняется методом последовательного вычитания вероятностей из сгенерированного датчиком числа (в диапазоне от 0 до 1) до момента попадания результата в отрицательную область. 

Для обеспечения математической корректности и оптимизации алгоритма поиска реализована обязательная предварительная подготовка данных (в классе `EventModeler`):
1. **Автоматическая нормировка:** перед запуском проверяется сумма заданных вероятностей исходов. Если она не равна единице (с учетом погрешности вычислений `float`), выполняется их пропорциональный пересчёт.
2. **Сортировка вероятностей:** списки событий (как для первой, так и для второй части) предварительно сортируются по убыванию вероятности с помощью классического алгоритма **пузырьковой сортировки**. Это гарантирует, что наиболее вероятные события будут проверяться первыми.

Архитектура проекта построена на принципах ООП (Объектно-ориентированного программирования). Логика работы датчика, математический аппарат моделирования событий и визуальная часть (GUI) полностью изолированы друг от друга в независимых модулях, что обеспечивает хорошую структуру репозитория и масштабируемость кода.
