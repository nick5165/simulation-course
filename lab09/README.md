# Отчет о результатах моделирования СМО M/M/1/0 (без очереди)

## 1. Описание исследуемой системы
Модель представляет собой одноканальную систему массового обслуживания с отказами (классическая модель M/M/1/0):
*   **Входящий поток:** простейший (пуассоновский) с интенсивностью $\lambda$. Интервалы времени между поступлениями заявок распределены по экспоненциальному закону.
*   **Обслуживание:** один канал (обработчик) с интенсивностью обслуживания $\mu$. Время работы прибора также распределено экспоненциально.
*   **Буфер (очередь):** отсутствует. Если заявка застает обработчик занятым, она мгновенно теряется (получает отказ) и не влияет на дальнейшую работу системы.

---

## 2. Метод моделирования и собираемая статистика
Моделирование реализовано на основе дискретно-событийного подхода (Discrete Event Simulation). В качестве генератора случайных чисел используется мультипликативный конгруэнтный алгоритм, а экспоненциальные интервалы моделируются методом обратной функции.

Программа фиксирует хронологию переходов системы между двумя состояниями:
*   **Состояние 0:** обработчик свободен.
*   **Состояние 1:** обработчик занят.

На основе накопленных данных рассчитываются следующие наблюдаемые показатели:
1.  **Общее число поступивших заявок** ($N_{вх}$).
2.  **Количество успешно обработанных заявок** ($N_{обсл}$).
3.  **Количество потерянных заявок** ($N_{пот}$).
4.  **Наблюдаемая вероятность простоя прибора ($P_0$):** отношение суммарного времени нахождения в состоянии 0 к общему времени симуляции.
5.  **Наблюдаемая вероятность занятости прибора ($P_1$):** отношение суммарного времени нахождения в состоянии 1 к общему времени симуляции.
6.  **Наблюдаемая вероятность отказа ($P_{отказа}$):** доля потерянных заявок от общего числа пришедших ($N_{пот} / N_{вх}$).
