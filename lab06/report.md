# Отчет по лабораторной работе: "Имитационное моделирование дискретных и непрерывных случайных величин"

## 1. Цель работы
Реализовать программный комплекс с графическим интерфейсом для моделирования дискретных и непрерывных (нормальных) случайных величин (СВ) с использованием алгоритмов генерации ПСЧ (псевдослучайных чисел), реализованных вручную. Провести статистический анализ точности моделирования при различных объемах выборки.

## 2. Описание алгоритмов генерации

### 2.1. Базовый равномерный генератор
Для получения случайных чисел в интервале $[0, 1)$ использован **мультипликативный конгруэнтный метод**:
- **Формула:** $x_{i+1} = (x_i \cdot \beta) \mod M$
- **Параметры:** $M = 2^{63}$, $\beta = 2^{32} + 3$.
- Это обеспечивает высокую длину периода и равномерность распределения.

### 2.2. Дискретная случайная величина
Моделирование пяти событий с заданными вероятностями $p_1, p_2, \dots, p_5$ реализовано методом **обратных функций (интервалов)**:
1. Отрезок $[0, 1]$ разбивается на 5 интервалов: $[0, p_1), [p_1, p_1+p_2), \dots$
2. Генерируется число $U \in [0, 1)$.
3. Определяется номер интервала, в который попало число $U$. Этот номер и является значением СВ.
4. **Нормировка:** Если сумма введённых пользователем вероятностей $\neq 1$, программа выполняет деление каждой вероятности на их общую сумму.

### 2.3. Нормальная случайная величина
Использован метод, основанный на **Центральной Предельной Теореме (ЦПТ)**:
1. Суммируется $k = 32$ независимых равномерно распределенных величин $U_i$.
2. Вычисляется центрированная величина: $Z = \frac{\sum_{i=1}^{k} U_i - k/2}{\sqrt{k/12}}$.
3. Итоговое значение с заданными $\mu$ и $\sigma$: $X = \mu + Z \cdot \sigma$.

## 3. Статистическая проверка
Для оценки качества моделирования в работе вычисляются:
- **Выборочное среднее ($\bar{x}$)** и **Выборочная дисперсия ($S^2$)**.
- **Относительные погрешности** параметров относительно теоретических значений.
- **Критерий Хи-квадрат ($\chi^2$):**
  - Вычисляется статистика: $\chi^2 = \sum \frac{(n_i - np_i)^2}{np_i}$.
  - Сравнивается с критическим значением $\chi^2_{1-\alpha, df}$ при уровне значимости $\alpha = 0.05$.

## 4. Описание реализации
Проект разделен на три модуля:
1. `logic.py`: Содержит классы ручных генераторов (`MultiplicateConGenerator`, `NormalDistributionGenerator`) и математические расчеты.
2. `gui.py`: Реализует интерфейс на базе библиотеки `tkinter` и визуализацию графиков через `matplotlib`.
3. `main.py`: Точка входа в приложение.

**Функционал GUI:**
- Ввод 5 вероятностей для дискретной СВ.
- Ввод $\mu$, $\sigma^2$ и размера выборки $N$.
- Автоматическая проверка условия нормировки с уведомлением пользователя.
- Построение гистограмм (для дискретной — сравнение столбцов, для нормальной — гистограмма и кривая плотности).

## 6. Вывод
В ходе лабораторной работы было установлено, что реализованные вручную генераторы (мультипликативный конгруэнтный и нормальный на основе ЦПТ) адекватно моделируют случайные процессы. 

Основные наблюдения:
1. **Закон больших чисел:** С ростом объема выборки $N$ выборочные среднее и дисперсия стремятся к их теоретическим значениям, а относительная погрешность уменьшается.
2. **Критерий $\chi^2$:** Данный метод проверки подтвердил, что распределение полученных псевдослучайных чисел соответствует теоретическим законам при достаточных объемах выборки.
3. **Визуализация:** Гистограммы являются наглядным инструментом подтверждения корректности работы алгоритмов: для дискретной СВ высоты столбцов соответствуют вероятностям, а для нормальной СВ огибающая гистограммы совпадает с теоретической кривой Гаусса.
4. **Важность нормировки:** Проверка условия $\sum p_i = 1$ критически важна для корректной работы алгоритма дискретных интервалов.
