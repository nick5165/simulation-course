# Отчет по лабораторной работе №10

**Тема:** Моделирование системы массового обслуживания (СМО) с усложнениями с использованием парадигмы объектно-ориентированного программирования.

## 1. Цель работы
Разработать программную модель системы массового обслуживания типа M/M/c/K (марковский входящий поток, марковское время обслуживания, многоканальная система с ограниченной очередью). Перевести базовую структуру программы на объектно-ориентированный подход и реализовать два дополнительных усложнения.

## 2. Постановка задачи
В качестве базовой системы выступает СМО с использованием собственного генератора псевдослучайных чисел (мультипликативный конгруэнтный метод). 

Были выбраны и реализованы следующие **усложнения**:
1. **Ограничение числа приборов (многоканальность):** система содержит `c` независимых каналов (приборов) обслуживания.
2. **Очередь ограниченной емкости:** если все приборы заняты, поступающая заявка помещается в очередь вместимостью `K`. Отказ в обслуживании (потеря заявки) происходит только в том случае, если заняты все приборы и очередь полностью заполнена.

Программа должна рассчитывать основные вероятностные характеристики СМО: вероятности пребывания системы в каждом из возможных состояний и вероятность отказа.

## 3. Архитектура программы (ООП)
Для реализации системы были спроектированы следующие классы:
*   `MultiplicateConGenerator` — отвечает за генерацию равномерно распределенных псевдослучайных чисел в диапазоне (0, 1).
*   `Server` — описывает логику работы отдельного прибора обслуживания. Инкапсулирует состояние прибора (свободен/занят) и время его освобождения. Содержит методы для назначения задачи (`assign_task`) и освобождения (`release`).
*   `QueuingSystem` — центральный класс-менеджер. Содержит массив объектов `Server` и переменную размера очереди. Управляет основным циклом имитационного моделирования (событийно-ориентированный подход), генерирует потоки заявок, управляет маршрутизацией заявок (на свободный прибор, в очередь или в отказ) и ведет учет времени пребывания системы в каждом состоянии для последующего расчета статистики.
