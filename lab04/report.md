# Отчет по лабораторной работе: Базовые датчики случайных чисел

## 1. Описание реализованных алгоритмов
В рамках работы были реализованы два типа генераторов псевдослучайных чисел (ГПСЧ):
1. **Мультипликативный конгруэнтный генератор (МКГ)** — базовый датчик с параметрами $M = 2^{63}$ и $\beta = 2^{32} + 3$.
2. **Запаздывающий генератор Фибоначчи** — продвинутый метод, использующий МКГ для инициализации начального заполнения (55 значений) и работающий по принципу сложения элементов с задержками 55 и 24.

## 2. Результаты тестирования (выборка 100 000 значений)

| Источник данных | Выборочное среднее | Выборочная дисперсия |
| :--- | :--- | :--- |
| **Теоретические значения** | **0.50000** | **0.08333** |
| Реализованный МКГ | [0.50061] | [0.08347] |
| Генератор Фибоначчи | [0.50106] | [0.08342] |
| Встроенный `random` (Python) | [0.49994] | [0.08340] |

## 3. Вывод
1. **Корректность реализации:** Оба разработанных генератора продемонстрировали статистические показатели (среднее и дисперсию), максимально близкие к теоретическим значениям для равномерного распределения на отрезке [0, 1]. Отклонения находятся в пределах допустимой статистической погрешности для выборки объемом $10^5$.
   
2. **Сравнение методов:** 
    * Базовый **МКГ** успешно прошел тест на простейшие статистические моменты, подтвердив свою работоспособность как простейшего датчика.
    * **Генератор Фибоначчи**, несмотря на использование МКГ для "разгона", показал стабильные результаты, сопоставимые с эталонным встроенным генератором языка Python. Это подтверждает эффективность алгоритма "перемешивания" накопленной истории значений.
    
3. **Итог:** Реализованные датчики пригодны для использования в задачах имитационного моделирования, требующих равномерно распределенных случайных величин.
